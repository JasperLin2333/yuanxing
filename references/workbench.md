# 元形工作台

本地原型与截图的模块画布编辑工具。使用原生 HTML/CSS/JavaScript、Node.js 和标准库，图算法依赖随工具保存，无 npm 安装步骤。工作台外壳统一采用 13px 正文、14/16px 标题与 12px 辅助文字，沿用绿色选中态；顶栏、目录、说明面板、表单、菜单和标记浮层使用一致的颜色、间距与控件样式。

## 打开与分享

在项目目录中启动工作台。编辑端自动保存到当前项目。顶部常驻「流程画布 / 需求文档 / 完整原型」切换：完整原型合并同一产品的全部模块，仅在不同产品或平台间切换；按 Esc 或点击「流程画布」返回，保留原画布的位置、缩放和选中内容。鼠标悬浮「导出 HTML」，可选择评审工作台、交互需求文档或独立原型，同伴下载后直接打开。菜单也支持点击和键盘操作。

需求文档可自由输入标题与正文，插入图片、分栏和表格，在表格两侧继续插入页面或组件；通过块旁操作移动内容，拖动列间分隔线调整宽度。原型在文档内直接操作，正文与说明可原位修改；导出后保留阅读布局与原型交互。数据结构及研发读取方式见[交互式需求文档](document.md)。

通用入口（Node.js 20+）：

```sh
node scripts/yuanxing.mjs serve --root ./my-prototype --open
```

本地地址默认 `http://127.0.0.1:4318`，可用 `--port` 改端口。关闭启动终端结束服务。`--builder` 为项目内的可选固定状态组装脚本；没有脚本的项目直接读取其 HTML 状态。可用 `--validator` 指定项目的导出校验脚本，导出前以 `--validate` 调用。 构建失效检查覆盖组装脚本所在目录、公共组件、模块、参考图片及节点的资源路径和 render 配置，辅助 Python 脚本修改后也会重新组装。

## 编辑来源

每个项目的 `artifact/workbench.json` 是模块编排、连线和批注的编辑来源。页面和图片路径均相对 `artifact`，没有该文件时可导入已有 `manifest.json` 的页面、转移和说明。

- `modules`：稳定的模块标识、标题及画布分区；`sections` 按讲解顺序定义模块内分区，节点通过 `section` 归属。目录顺序和画布分区使用同一配置。
- `nodes`：稳定状态标识、所属模块、类型（`html / image / note`）、原始画布尺寸、位置、页面说明及资源路径；可用 `canvasType: pc / mobile` 指定卡片类型，只影响画布展示，不改变原始尺寸。重复场景可用 `overview: false` 不在概览和目录中重复展示，仍保留页面内对应交互。
- 条件分叉使用 `kind: note, presentation: branch` 保存线上的共用分叉点；画布只显示连接点，条件名称标在线上，不作为页面卡片。`diagram: true` 连线只表达画布层级；原产品交互通过 `canvasFrom` 挂到线组时仍保留原页面及按钮绑定。
- 同一页面的重复状态用 `overviewAlias` 指向一个可见节点，概览连线合并到该节点；实际页面仍展示各自状态，避免重复画下拉菜单或表单。
- `edges`：来源状态、目标状态、操作名称、分支条件和说明。HTML 使用 `selector` 绑定控件，截图使用相对坐标 `rect: [x, y, width, height]`；`trigger: next` 保留为流程关系，不生成查看栏跳转按钮。手动拖线的 `fromSide / toSide` 保存所选端点方向，新增或改接连线不会覆盖已有端点。
- `contextDefaults`：演示从页面直接进入时采用的默认条件。连线以 `setContext` 记录前面的选择，以 `when` 限定后续适用分支；共享页面无需让查看者重复选择。条件值使用字符串、布尔值或数字，编辑版和离线分享版采用同一规则。
- 概览只画主要流程。通用导航 `navigation: true` 和非主要连线 `overview: false` 不画在画布上；页面内的取消、返回和重复切换仍保留，分享文件沿用相同展示规则。用户手动新建的连线默认显示。
- `annotations`：正文以及关联页面或连线；截图标记使用 `point: [x, y]`，HTML 标记可使用稳定元素选择器和元素内相对位置。
- `rules`：共用规则正文。页面和连线以 `rule` 引用，避免重复维护。
- `referencePositions`：跨模块引用页面在当前模块中的位置，按模块及页面标识保存；拖动引用不会改变原页面在所属模块中的位置。

## 编辑行为

左侧目录顶部点击“＋”新增模块，创建后直接进入空白画布，在右侧“模块名称”中改名。所有模块均支持删除，包括原有模块与非空模块；删除时一并移除所属页面、连线和标记，保留原型源文件，可撤销。删除最后一个模块后保留一个空白模块。模块与画布修改自动保存。

画布是主要编辑区域：点击左下工具栏的「＋」或右键空白处添加图片、说明节点；图片也可直接粘贴或拖入。双击空白处不创建内容。单击节点选中，拖动可移动；双击标题或缩略图打开完整页面，原型、图片与说明节点操作一致。画布提供 PC 和移动端两种节点：PC 保留 400 × 290px 横向卡片，移动端采用 240 × 560px 竖向卡片（预览区按 375 × 812 的手机比例）。已有移动端原型自动使用移动端类型，图片和说明默认 PC，可在右侧“节点类型”切换。两种类型内尺寸分别统一，内容完整等比居中缩略，长图不裁切，切换类型不改节点位置或原始内容尺寸。原始尺寸保持不变，分叉连接点仍为小圆点。只读分享版也使用双击打开。左下的四角箭头图标用于适应画布。

单独选中节点后显示四边连接点，从圆点拖到另一节点建立连线；经过目标节点时显示目标的四边连接点。普通悬浮与多选不显示连接点。选中连线后，在右侧编辑操作名称与说明正文；普通连线和分支都只保留“操作名称”与“说明正文”，不提供独立“分支说明”输入项；已有分支文字沿用同一个操作名称输入项编辑；显示两端圆点和线中间的「＋」，拖动起点更换来源，拖动终点更换目标。在空白处松手或按 Esc 取消连接。起点更换页面后清除原页面的控件绑定；更换目标时保留原控件绑定。选中可操作的连线后，可绑定或重新绑定页面点击区域；项目扩展可关闭该入口，沿用项目自己的控件绑定。

新增连线、改接任意一端或增加线组分支时，保留所有已有页面的位置和连线端点。四边连接点均可作为起点或终点，按松手时选择的方向保存；页面不会因新关系自动换行、翻转或整体重排。同侧端点不自动排序或重新分配；线与线允许交叉，不为了减少交叉而改动其他线。只有主动点击线中间的「＋」新增分支或连接分叉点才建立分支关系。改线支持撤销、保存及导出。

画布采用自由手动布局，向上、向左均可越过原点，支持负坐标；拖动、微移、吸附、对齐、等间距、粘贴、连线折点、保存及离线分享保持同一套坐标。空白处拖动框选多个节点，Shift 点击标题栏或缩略图可加选、取消选中；Shift 框选追加到已有选择。⌘A / Ctrl+A 选中当前画布全部可见节点，Esc 或点击空白取消选择。多选时隐藏所有页面的四边连接点；拖动任一节点整体移动，保留各节点的相对位置；移动与撤销按整组处理。单选时拖动标题栏只移动当前节点，靠近其他页面的上、下、左、右边缘或中心线时显示辅助线并吸附，松手保留对齐位置；按住 Alt 可自由摆放。对齐线在隐藏流程连线时仍可见。跨模块引用只保存当前画布的位置。添加图片、修改内容、刷新或切换模块均保留现有位置。`adaptCanvasLayout` 仅供明确要求重新排布时由脚本调用，普通连线编辑不调用。

同一页面可连向多个目标，分别填写分支条件，例如未购买套餐时的管理员与非管理员。点击连线或线上的文字选中，再点左下工具栏或右侧的「删除连线」，也可按 Delete / Backspace；只删除关系和该连线的批注，保留两端页面。⌘Z / Ctrl+Z 撤销；输入文字时保留文本编辑快捷键。

删除支线后，只有一个后续方向的分叉点自动收拢，主线接回；同一可见主线对应的多个实际按钮分别保留。直接删除分叉点时，仅移除连接点并接回前后关系，不删除整个链条；点上的名称、说明和标记保留到接回的连线。剩余多个方向时继续保留分叉点，删除与收拢合为一次撤销。

选中现有连线后，在线段中间直接显示「＋」；点击后再点击目标页面即可新增支线，点击空白处或按 Esc 取消，取消不产生节点或连线。原路线在该点拆为共用主线和原支线，保留原目标、控件绑定、条件、文字位置及折线路径，不自动移动已有页面或分叉点。已有支线上也可按相同方式继续分叉。分叉点可以单独拖动，缩小画布时仍保留便于操作的命中区域；选中支线可编辑各自条件。靠近所选线段时显示折线控制点，可拖动调整该段。不提供独立添加分支节点的入口，分支只从现有连线上的「＋」创建。

拖动页面后，只处理端点变化或被移动节点挡住的线，保留手选的上下左右方向和其他线的路线。连线先生成一条横平竖直的合理路线，能直连就直连，绕行尽量少拐弯、不绕远，必须避开节点整个卡片及标题；拖动连接时的预览也遵循避障规则。画布隐藏默认的“继续”文字，保留分支条件和其他操作名称；页面内的下一步操作仍然保留。操作文字按实际宽高放在线段旁，长说明换行并避开节点；新增其他线不挪动原有文字，文字可自行拖动。左下工具栏的连线图标可隐藏或恢复所有连线，隐藏只影响显示。刷新会恢复上次的模块、页面、流程选择、画布位置和连线显示状态，编辑端与离线分享端分别记忆。

点击画布空白处取消当前页面、连线或分叉点的选中状态。编辑端在空白处拖动用于框选；按住空格拖动或用鼠标中键拖动平移画布，触控板滚动也可平移。只读分享版保留空白处拖动平移。

双击画布中的页面或图片打开完整页面，单击用于选中和整理。查看栏的页面标题居中，返回概览按钮保留在左侧。右侧只保留一份“说明正文”，合并展示原页面说明与交互规则正文；修改后的正文保存在当前页面或连线上。画布视图不显示顶部“打点说明”图标，打开完整页面后才显示。点击该图标，再点击页面位置；标记旁直接出现文本浮层，下方提供删除、取消和保存，不提供语音。点击保存提交说明，并按编号显示在右侧“标记说明”中；取消、点击外部区域或按 Esc 放弃本次输入，新建且未保存的标记同时移除；Ctrl/⌘＋Enter 保存。已有标记可继续修改文字或删除。顶部用图标显示“撤销”，支持 ⌘Z / Ctrl+Z，不提供重做。连续方向键微移合并为一次撤销；撤销历史最多保留最近 100 次操作，并受 8 MiB 的序列化文本估算容量限制。源码外部变更不会覆盖已编辑但未保存的内容，输入、拖动、标记浮层和完整原型体验期间暂缓自动更新。独立字段修改自动合并，同一内容冲突时保留双方修改，可选择保留自己的或采用外部的冲突项，也可导出双方内容。工作台代码变更稳定后在空闲时自动重载，并恢复原模块、页面和画布位置。

修改自动保存，不显示日常保存提示；保存失败时保留编辑内容，提供重试和导出当前修改的操作。 普通操作提示 5 秒后自动消失，所有提示均可点击右侧关闭；保存失败提示保留重试和导出入口，由用户手动关闭。节点可手动调整；新增、连线、改接或删除节点均不自动重排其余页面，留出的空位由用户拖动整理。原型 HTML、图片及说明节点均可点击右侧面板右上角的删除图标，也可用 Delete / Backspace 删除所选节点；多选支持成组删除。右上角始终保留删除节点按钮，选中或编辑标记时也可直接删除节点及其全部标记和关联连线；单条标记在右侧对应说明行提供独立删除图标，两种操作不互相替换。仅移除画布编排及关联关系，保留源文件。跨模块引用使用“移除当前画布引用”，保留来源页面。删除节点与连线均可撤销，没有全画布重排入口。

右侧「说明正文」支持直接粘贴图片，文字和图片一起编辑、自动保存；打开流程说明节点后，也可在中央说明页粘贴图片。图片保存在项目的 `artifact/assets/`，在说明正文中以 Markdown 图片引用维护，保留当前节点和连线。分享导出时自动内嵌说明图片，离线查看不依赖本机路径。

顶部两侧的面板按钮可分别折叠模块目录和页面说明，并记住本机的显示偏好。左下角百分比可直接选择 10%、25%、50%、75%、100%、125%、150%、200%、250%，捏合或加减后显示实际比例。触控板捏合以光标位置为中心缩放；“缩放设置”悬浮显示文字提示，可调灵敏度 0.5×～6×，步长 0.1×，默认 3.5×，记住本机选择，点击画布或面板外部自动收起设置，面板内调整滑杆时保持展开，普通双指滚动仍用于平移。流程说明页按实际内容高度展示，默认缩放到完整可见；可放大阅读，点击「适应画布」恢复完整显示。

分享版保留搜索、定位页面和查看标记说明，修改能力关闭。通用 HTML 在隔离的页面中运行自己的脚本，通过已声明的控件绑定与截图热点连续跳转。项目也可通过显式扩展提供声明式播放器：页面脚本会被移除，交互由扩展处理；相同扩展随项目的离线 HTML 内嵌。

## 整理与查找

- 选中节点后，右侧移除常用操作区的打开、聚焦、编组入口；多选时提供六种对齐及横向、纵向等间距，不提供复制或创建副本按钮。对齐以第一个选中节点为基准，等间距保留首尾位置。方向键移动 1 px，Shift＋方向键移动 10 px。F 聚焦所选，无选择时适应整张画布。
- ⌘C / Ctrl+C 复制、⌘X / Ctrl+X 剪切、⌘V / Ctrl+V 粘贴所选页面或流程；剪切仅在成功写入剪贴板后移走原节点及关联关系，支持撤销；跨模块引用只移除当前画布的引用，不删除来源页面。⌘D / Ctrl+D 创建副本。复制仅携带所选内容及其依赖组件、说明图片；剪切、粘贴后仅增删或更新受影响卡片，保留其他缩略图，后台过期响应不覆盖刚完成的编辑。副本保留相对位置、组内真实操作链、批注与独立的交互说明，关联的隐藏状态一起复制并继续隐藏，布局避让已有节点。HTML 状态使用独立路径，普通 HTML 在首次保存时复制源文件；截图沿用图片资源，替换副本截图不影响原节点。
- 不提供编组、编组名称或编组快捷键；页面独立选择，可通过框选或 Shift 临时多选后一起移动。复制粘贴不携带编组，新增或复制不会重排已有内容。
- 左侧只保留一个“搜索页面”入口，按名称部分匹配所有模块的画布页面。结果只显示页面名称和所属模块，单击整行切换到所属模块画布、居中缩放并选中目标，不直接打开详情；目录中的页面也只用于定位，双击画布节点才打开页面。搜索词和结果在定位后保留，清空后恢复模块列表；无结果显示“未找到相关页面”。隐藏的重复状态按 `overviewAlias` 命中保留节点并合并结果，没有可见对应节点的独立隐藏页面不列入搜索，页面内交互仍保留。不提供“全部页面”弹窗、显示状态筛选及显示／隐藏操作。⌘K / Ctrl+K 展开目录并聚焦搜索框。
- 鼠标悬浮或键盘聚焦模块行时显示排序把手和删除图标；所有模块使用同一删除操作。把手可拖动排序，也可用上下方向键调整顺序。
- 选中连线后，鼠标靠近哪条线段，就显示该段的方形控制点，拖动可调整折线；拖动说明文字调整位置，四边端点继续随页面移动。拖动线段会保存手动折点；首尾保留向外的短引线，线头圆点贴合实际端点。会穿过节点、折返或绕回自身的拖动不生效，保留上一个有效位置。手动修改与撤销、保存及分享导出一致。
- 左侧“回收站”直接打开画布，从左侧模块目录切换回对应模块；画布顶部不另设标题、操作提示或返回栏。隐藏的原型页面、图片和说明按四列网格排列，卡片标注所属模块，使用完整等比缩略图。支持缩放、平移、框选、Shift 多选、拖动及双击预览；回收站位置独立保存，预览返回保留画布位置。选中内容直接复制或剪切，到模块画布粘贴为正常可见节点；复制保留回收站原件，剪切移走所选原件，均保留说明和标记。也可向回收站粘贴，内容继续隐藏。没有“放回画布”按钮、列表视图或第二个搜索入口；现有节点删除行为保持不变。
- 图片上传支持多选，粘贴或拖入多张图片按行排列，避让已有节点；本次导入按一次撤销处理，不移动原来的画布。
- 打点后在标记旁直接输入，浮层提供文本框、删除、取消和保存，不提供语音，保存后右侧按编号显示内容；不提供独立评论列表、处理状态或关联说明区域。页面说明与交互规则正文合并为一个编辑区，保留已有文字。

节点和模块删除后立即生效，不弹出浏览器确认框；误删可使用顶部撤销或 ⌘Z / Ctrl+Z 恢复。

所有按钮和图标按钮统一使用悬浮文字提示，说明对应功能；提示在点击或滚动时收起。标记说明点击保存提交，其他编辑自动保存到当前项目，打开时读取最新内容，不提供版本列表或恢复操作。

## 连线

每条连线独立避开节点，不以其他线为障碍，不交换端口或整理其他路径。新建时只生成新线，改接时仅重新生成被改接的线，移动节点时仅处理端点改变或被挡住的线。有效的手动路线原样保留；节点挡住手动路线时只修复该线，不覆盖保存的折点。节点重叠或连接方向没有通道时，不提交穿过节点的连线。

连线使用圆角折线，拖拽预览与落线共用避障与端点方向，接近目标端点时吸附并高亮具体方向。双击线条或说明文字可直接编辑名称，Enter 保存、Esc 取消；线段按横向或纵向拖动，新增分叉的「＋」与线段把手分开。

箭头位于节点上层，尖端贴合节点边缘，缩放时保持大小。选中连线后，改接把手在悬浮、键盘聚焦或拖动时显示；页面端把手位于边缘内侧，与箭头分开，不被卡片裁切。

分叉点靠近目标页面时，引线长度随可用间距缩短，避免固定引线把支线挤到页面另一侧再折返；实际手动折点仍按已有规则保留。

分叉点在缩放后保持可抓取大小，拖动时对齐其他端点，不能拖进页面或使相连路径失去通道。从现有分叉的连接点继续拖线可扩展分支；从其他线段的「＋」拉线才新增分叉点。拖线、点击后选目标均支持 Esc 取消，取消或未连接目标不新增节点。多条实际按钮共用一条可见连线时一并挂接到分叉，实际跳转、条件和说明保持独立。

不提供「重排所选流程」。页面位置由用户拖动整理，也可使用对齐和等间距；新增、改接、删除连线与从线上新增分支均保留已有页面位置。

图算法依赖、固定版本和许可证见 [连线依赖](../runtime/THIRD-PARTY-README.md)。离线分享沿用相同的布线行为。

## 本地接口

`GET /api/project/status` 只返回编排与资源版本，未变化时不下载页面和图片，后台标签页暂停轮询；`GET /api/project` 读取项目和页面资源；`PUT /api/project` 以文件版本核对保存；`POST /api/image` 保存图片；`POST /api/export` 内嵌当前范围生成 HTML。写入请求需要本地会话令牌。仅监听本机，文件访问限定在选中项目内。

## 项目与完整原型

顶栏左侧切换已登记项目，中间切换「流程画布／完整原型」，右侧保留当前视图所需操作。新增项目、模块归属、产品入口和交互串联可直接通过对话交给 Agent；工作台不增加项目管理表单。

同一产品的模块共享一份完整原型，沿页面自身的导航连续操作。确属独立产品或平台时才显示产品／平台选择，不按模块列体验入口。画布连线与控件跳转分别维护；有设计的交互应可操作，没有设计的功能不补造。

画布和回收站仅在页面进入视野附近时分批创建预览，离屏后释放 iframe。双击仍可打开完整页面，复制、剪切、粘贴和位置保留不受预览加载影响。

完整原型中的 HTML 由页面内的实际控件接收鼠标和键盘事件，保留原生悬浮、焦点、滚动和表单。声明式项目由项目播放器响应这些事件；不使用父页面上的透明按钮或替身输入框覆盖 HTML。浮动菜单相对当前触发元素定位，截图继续使用热点。

完整原型中，按钮关联的图片在预览层打开，点击「返回」或按 Esc 回到来源页，保留来源页的输入和滚动位置。图片之间可沿已有热点继续跳转并逐层返回；热点指向页面时继续原流程。


## 局部 UI 开发交付

右上角「⋯ → 开发交付模式」切换，默认关闭。普通画布、原型体验不显示拾取工具。开启后打开 HTML 页面，点击需要交付的区域，通过上方的层级按钮选择更大的父级区域；可复制交付内容、复制 HTML 或下载片段 HTML。退出按钮或 Esc 关闭此模式。

模式使用只读预览，保留原页面 iframe，退出后恢复原来的页面与输入。普通脚本页面通过受会话令牌约束的页面桥传回当前 DOM 快照；不会为提取而放开原页面的脚本权限。截图与说明节点不提供 DOM 提取。

交付内容包含页面和模块背景、预览路径、项目扩展提供的编辑源文件、选区 DOM、页面样式、组件标记、SVG 符号依赖、页面与关联标记说明。下载片段保留祖先容器及 body 属性作为布局上下文，兄弟区域不一起导出；脚本、事件处理和拾取高亮不进入片段。片段用于局部 UI 对照，原页面交互与真实业务实现仍应沿用项目源。

## 修改说明与跨页面同步

页面和连线的「说明正文」继续直接编辑，修改作用于当前对象；离线分享保持说明只读。

需要跨页面调整时，在使用元形的当前对话中提出范围与规则，例如“所有涉及安装技能的地方，都改成安装后默认对全部专家启用”。Agent 根据业务含义查找相关页面、说明和交互，核对并同步本轮范围内的内容，再说明受影响的位置与差异；不只匹配相同逻辑标识或字面文本。工作台不增加共用逻辑管理入口或独立 AI 输入框，当前页编辑也不自动触发跨页修改。
