# 元形工作台

本手册说明人在工作台界面里的操作与表现，回答界面行为问题时按章节读取：打开与分享、编辑来源、编辑行为、整理与查找、连线、本地接口、项目与完整原型、局部 UI 开发交付、修改说明与跨页面同步。项目数据格式见[项目格式](project-format.md)，需求文档与离线数据见[交互式需求文档](document.md)。

本地原型与截图的模块画布编辑工具。使用原生 HTML/CSS/JavaScript、Node.js 和标准库，图算法与离线解压依赖随工具保存，无 npm 安装步骤。工作台外壳统一采用 13px 正文、14/16px 标题与 12px 辅助文字，沿用绿色选中态；顶栏、目录、说明面板、表单、菜单和标记浮层使用一致的颜色、间距与控件样式。 项目、产品或平台、节点类型和缩放比例使用同一个选择组件，支持键盘选择。

## 打开与分享

设计阶段默认打开可编辑工作台，可直接拖动页面、编辑说明、粘贴图片，并继续让 AI 修改。桌面“元形工作台”入口与顶栏「⋯（更多）」菜单中的「打开工作台」调用同一个本机启动器，工作台已运行时直接打开，未运行时先启动；多项目恢复上次打开的项目。顶栏「⋯（更多）」在本地与离线端统一排列「开发交付模式」「打开工作台」与「快速上手」（「开发交付模式」在需求文档视图中隐藏）；点击「打开工作台」只打开本机工作台，由用户选择项目，离线文件本身保持只读。首次设置及桌面入口安装见[本机启动](agent-adaptation.md#本机启动与桌面入口)。

在项目目录中启动工作台。编辑端自动保存到当前项目。顶部常驻「流程画布 / 需求文档 / 完整原型」切换：完整原型合并同一产品的全部模块，仅在不同产品或平台间切换；按 Esc 或点击「流程画布」返回，保留原画布的位置、缩放和选中内容。点击顶栏「导出」，提供「导出工作台」（完整离线工作台 HTML）与「导出需求文档」（纯 Markdown `.md` 文件）两项：导出工作台排除回收站页面及其独占数据，但共用资源和整份项目扩展脚本可能含有相关代码；原型交互所需的内部状态仍保留。菜单也支持点击和键盘操作。刷新恢复上次打开的视图；需求文档同时恢复阅读章节及滚动位置，偏好按项目在当前浏览器保存。

顶栏「更新说明」按日期和时间展示本项目的交付历史，有未读变化时显示提示点。点击「查看变更」展开改前和改后原文，点击「复制本次」把该条的日期、章节和原文复制为 Markdown。处理了多个批次时，可在「上次交付」选择已处理的记录，再点「复制至当前」。同一规则的中间改动保留在历史中，区间复制只呈现起点和当前版。离线工作台支持同样的复制操作，记录以该次导出的历史为准。

需求文档先说明背景、目标和功能，再按功能展开；长说明上下阅读，需要对照时再混用分栏和表格。可直接修订正文与说明的文字；独立文字块清空后，按退格键或 Delete 可删除该空块，误删可撤销。引用正文的段落和列表项清空后，按退格键、Delete 或离开编辑区会删除对应的原文行。选中同一段落、列表项或表格单元格内的文字后，点击【重点说明】标红，选中红字可点击【取消重点】，其他格式保留；引用 Markdown 的标红只保存在工作台编排，不向源 Markdown 写入代码标签。文档左侧目录通过与画布相同的顶栏按钮折叠；其他结构编排、原型引用和组件范围由 Agent 处理。原型外框右下角可拖动等比调整宽高，内部页面自动适应，本地保存比例，离线分享可临时调整；框内缩放和平移保留外框尺寸。底部工具栏靠右，刷新图标只重启当前画布，回到配置的初始页面与状态并清除本轮输入，保留外框大小、文档阅读位置及其他画布；离线分享同样支持。已有 Markdown PRD 按章节引用，直接修订写回原文对应文字；导出带上所选正文及原型交互。数据结构及研发读取方式见[交互式需求文档](document.md)。

流程图也可像原型一样嵌入正文：右下角调整外框以减少篇幅，框内【缩小】【放大】【适应】及拖动用于查看细节。本地保存外框大小，离线分享保留导出时的比例；HTML 图源与普通 Markdown 使用的图片保持对应。

通用入口（Node.js 20+）：

```sh
node "<Skill目录>/scripts/yuanxing.mjs" open --root "<项目目录>" --reuse
```

本地地址默认 `http://127.0.0.1:4318`，可用 `--port` 改端口。`open --reuse` 在后台启动或复用工作台，仅新启动服务时自动开页，关闭启动终端不结束后台服务；需要手动重新打开时去掉 `--reuse`。`serve --open` 仍可用于前台运行，关闭其终端才结束该前台服务。`--builder` 为项目内的可选固定状态组装脚本；没有脚本的项目直接读取其 HTML 状态。可用 `--validator` 指定项目的导出校验脚本，导出前以 `--validate` 调用。 构建失效检查覆盖组装脚本所在目录、公共组件、模块、参考图片及节点的资源路径和 render 配置，辅助 Python 脚本修改后也会重新组装。

## 编辑来源

每个项目的 `artifact/workbench.json` 是模块编排、连线和批注的编辑来源。页面和图片路径均相对 `artifact`，没有该文件时可导入已有 `manifest.json` 的页面、转移和说明。

- `modules`：稳定的模块标识、标题及画布分区；`sections` 按讲解顺序定义模块内分区，节点通过 `section` 归属。目录顺序和画布分区使用同一配置。
- `nodes`：稳定状态标识、所属模块、类型（`html / image / note`）、原始画布尺寸、位置、页面说明及资源路径；可用 `canvasType: pc / mobile` 指定卡片类型，只影响画布展示，不改变原始尺寸。新编排以 `nodeStateVersion: 1` 区分展示与删除：`canvas: false` 隐藏画布卡片，`overview: false` 隐藏概览和目录；只有 `deleted: true` 记录删除，从播放及离线导出中排除，普通页面和说明可在回收站查看。旧编排的兼容规则见[项目格式](project-format.md#页面与画布)，不再用隐藏字段表达新的删除操作。
- 条件分叉使用 `kind: note, presentation: branch` 保存线上的共用分叉点；画布只显示连接点，条件名称标在线上，不作为页面卡片。`diagram: true` 连线只表达画布层级；原产品交互通过 `canvasFrom` 挂到线组时仍保留原页面及按钮绑定。
- 同一页面的重复状态可用 `overviewAlias` 指向一个可见节点，概览连线合并到该节点；实际页面仍展示各自状态，避免重复画下拉菜单或表单。别名只表达展示归并，不改变节点的删除状态。
- `edges`：来源状态、目标状态、操作名称、分支条件和说明。HTML 使用 `selector` 绑定控件，截图使用相对坐标 `rect: [x, y, width, height]`；`trigger: next` 保留为流程关系，不生成查看栏跳转按钮。手动拖线的 `fromSide / toSide` 保存所选端点方向，新增或改接连线不会覆盖已有端点。
- `contextDefaults`：演示从页面直接进入时采用的默认条件。连线以 `setContext` 记录前面的选择，以 `when` 限定后续适用分支；共享页面无需让查看者重复选择。条件值使用字符串、布尔值或数字，编辑版和离线分享版采用同一规则。
- 概览只画主要流程。通用导航 `navigation: true` 和非主要连线 `overview: false` 不画在画布上；页面内的取消、返回和重复切换仍保留，分享文件沿用相同展示规则。用户手动新建的连线默认显示。
- `annotations`：正文以及关联页面或连线；截图标记使用 `point: [x, y]`，HTML 标记可使用稳定元素选择器和元素内相对位置。
- `rules`：共用规则正文。页面和连线以 `rule` 引用，避免重复维护。
- `referencePositions`：跨模块引用页面在当前模块中的位置，按模块及页面标识保存；拖动引用不会改变原页面在所属模块中的位置。

## 编辑行为

左侧目录顶部点击“＋”新增模块，创建后直接进入空白画布，在右侧“模块名称”中改名。所有模块均支持删除，包括原有模块与非空模块；删除时一并移除所属页面、连线和标记，保留原型源文件，可撤销。删除最后一个模块后保留一个空白模块。模块与画布修改自动保存。

画布是主要编辑区域：图片可直接粘贴或拖入；画布不提供添加节点菜单。双击空白处不创建内容。单击节点选中，拖动可移动；双击标题或缩略图打开完整页面，原型、图片与说明节点操作一致。画布提供 PC 和移动端两种节点：PC 保留 400 × 290px 横向卡片，移动端采用 240 × 560px 竖向卡片（预览区按 375 × 812 的手机比例）。已有移动端原型自动使用移动端类型，图片和说明默认 PC，可在右侧“节点类型”切换。两种类型内尺寸分别统一，内容完整等比居中缩略，长图不裁切，切换类型不改节点位置或原始内容尺寸。原始尺寸保持不变，分叉连接点仍为小圆点。只读分享版也使用双击打开。左下的四角箭头图标用于适应画布。

悬浮或单独选中节点后在卡片外侧 14px 处显示四向连接点，从圆点拖到另一节点建立连线；经过目标节点时圆点贴回边框并在边框轮廓与四向圆点之间平滑吸附（按住 Shift 可按 45°/90° 方向对齐）。多选不显示连接点。选中连线后，右侧「连线说明」会自动跳过分叉点展示真实起终点页面，只保留“操作名称”和“说明正文”两个输入项以及右上角的「删除连线及其标记」图标；不提供绑定点击区域、连线悬浮工具栏或线中间「＋」分叉按钮，页面热点与控件绑定由 Agent 在原型与编排中维护。连线两端显示可拖动的改接圆点，拖动起点更换来源，拖动终点更换目标或重新贴靠边框任意位置；在空白处松手或按 Esc 取消连接。起点更换页面后清除原页面的控件绑定；更换目标时保留原控件绑定。

新增连线、改接任意一端或调整连线时，保留所有已有页面的位置和其余连线。四边连接点与边框任意位置均可作为起点或终点，按松手时选择的方向与相对锚点（`fromAnchor / toAnchor`）保存；页面不会因新关系自动换行、翻转或整体重排。同一页面可直接拖出多条连线指向多个目标；允许连线之间自由交叉，并在交点处自动生成飞书式跳弧。改线支持撤销、保存及导出。

画布采用自由手动布局，向上、向左均可越过原点，支持负坐标；拖动、微移、吸附、对齐、等间距、粘贴、连线折点、保存及离线分享保持同一套坐标。空白处拖动框选多个节点，Shift 点击标题栏或缩略图可加选、取消选中；Shift 框选追加到已有选择。⌘A / Ctrl+A 选中当前画布全部可见节点，Esc 或点击空白取消选择。多选时隐藏所有页面的四边连接点；拖动任一节点整体移动，保留各节点的相对位置；移动与撤销按整组处理。单选时拖动标题栏只移动当前节点，靠近其他页面的上、下、左、右边缘或中心线时显示辅助线并吸附，松手保留对齐位置；按住 Alt 可自由摆放。对齐线在隐藏流程连线时仍可见。跨模块引用只保存当前画布的位置。添加图片、修改内容、刷新或切换模块均保留现有位置。`adaptCanvasLayout` 仅供明确要求重新排布时由脚本调用，普通连线编辑不调用。

同一页面可连向多个目标，分别填写分支条件，例如未购买套餐时的管理员与非管理员。点击连线或线上的文字选中，点右侧栏右上角的「删除连线」，或直接按 Delete / Backspace 删除；只删除关系和该连线的批注，保留两端页面。⌘Z / Ctrl+Z 撤销；输入文字时保留文本编辑快捷键。

对于已有编排中的分叉点（`presentation: "branch"`），删除支线后只有一个后续方向时分叉点自动收拢，主线接回；同一可见主线对应的多个实际按钮分别保留。直接删除分叉点时，仅移除连接点并接回前后关系，不删除整个链条；点上的名称、说明和标记保留到接回的连线。剩余多个方向时继续保留分叉点，删除与收拢合为一次撤销。

选中连线后支持三种直接编辑方式：1）双击线条、双击文字，或选中后直接键盘键入 / 按 Enter / F2，在线上原地打开与画布文字卡片同字号同高的输入框即时编辑（Enter 保存、Esc 取消）；2）每条可用折线段中点显示细长拖拽手柄，拖动可横向或纵向调整折线（靠近同线其他拐点或端点自动对齐吸附，按 Alt 取消吸附，2 点直连拖动会自动拆出 U 形拐点，双击手柄清除手动折点并恢复自动路由）；3）拖动线上文字只沿当前连线轨迹滑动并保存 `labelT`（近中点时自动居中吸附），不会拖到空白画布。已有分叉点连线支持继续拖入新连接或改接。

拖动页面后，只处理端点变化或受影响的连线，保留手选的上下左右方向、边框锚点，并在单端移动时尽量保持用户手动折点中间段落不动、只衔接端点邻段。连线采用飞书式圆角折线自动绕行卡片（始终生成连续路径，不再因短暂遮挡转为红色虚线阻塞状态）；拖拽连接时的预览与落线共用同一路由规则。画布隐藏默认的“继续”文字，保留分支条件和其他操作名称；页面内的下一步操作仍然保留。操作文字默认按弧长中点直接压线居中遮断展示（不拉出引导线）。画布左下角工具栏仅保留缩放、适应画布和「隐藏/显示连线」开关（不设删线或整理连线按钮）；双击进入单页详情后，缩放与适应工具栏自动收拢到查看栏右侧，避免遮挡原型内容，图片节点的「替换图片」按钮也仅在详情查看栏右侧显示（画布卡片上不显示）。刷新会恢复上次的模块、页面、流程选择、画布位置和连线显示状态，编辑端与离线分享端分别记忆。

点击画布空白处取消当前页面、连线或分叉点的选中状态。编辑端在空白处拖动用于框选；按住空格拖动或用鼠标中键拖动平移画布，触控板滚动也可平移。只读分享版保留空白处拖动平移。

双击画布中的页面或图片打开完整页面，单击用于选中和整理。查看栏的页面标题居中，返回概览按钮保留在左侧。右侧展示当前页面或连线的核心说明；未设摘要的旧对象兼容读取原说明。编辑只更新摘要，详细规则继续在需求文档维护。画布中的页面缩略图直接显示已有批注标记，点击标记可打开对应说明；关联元素找不到时在原位置显示标记并提示核对；顶部“打点说明”图标在打开完整页面后显示。点击该图标，再点击页面位置；标记旁直接出现文本浮层，下方提供删除、取消和保存，不提供语音。点击保存提交说明，并按编号显示在右侧“标记说明”中；取消、点击外部区域或按 Esc 放弃本次输入，新建且未保存的标记同时移除；Ctrl/⌘＋Enter 保存。已有标记可继续修改文字或删除。顶部用图标显示“撤销”，支持 ⌘Z / Ctrl+Z，不提供重做。连续方向键微移合并为一次撤销；撤销历史最多保留最近 100 次操作，并受 8 MiB 的序列化文本估算容量限制。源码外部变更不会覆盖已编辑但未保存的内容，输入、拖动、标记浮层和完整原型体验期间暂缓自动更新。独立字段修改自动合并，同一内容冲突时保留双方修改，可选择保留自己的或采用外部的冲突项，也可导出双方内容。工作台代码变更稳定后在空闲时自动重载，并恢复原模块、页面和画布位置。

修改自动保存，不显示日常保存提示；保存失败时保留编辑内容，提供重试和导出当前修改的操作。 普通操作提示 5 秒后自动消失，所有提示均可点击右侧关闭；保存失败提示保留重试和导出入口，由用户手动关闭。节点可手动调整；新增、连线、改接或删除节点均不自动重排其余页面，留出的空位由用户拖动整理。原型 HTML、图片及说明节点均可点击右侧面板右上角的删除图标，也可用 Delete / Backspace 删除所选节点；多选支持成组删除。右上角始终保留删除节点按钮，选中或编辑标记时也可直接删除节点及其全部标记和关联连线；单条标记在右侧对应说明行提供独立删除图标，两种操作不互相替换。仅移除画布编排及关联关系，保留源文件。跨模块引用使用“移除当前画布引用”，保留来源页面。删除节点与连线均可撤销，没有全画布重排入口。

右侧节点、连线和分支的「说明正文」支持直接粘贴图片，文字和图片一起编辑、自动保存；打开流程说明节点后，也可在中央说明页粘贴图片。图片保存在项目的 `artifact/assets/`，在说明正文中以 Markdown 图片引用维护，保留当前节点和连线。分享导出时自动内嵌说明图片，离线查看不依赖本机路径。

顶部两侧的面板按钮可分别折叠模块目录和页面说明，并记住本机的显示偏好。左下角百分比可直接选择 10%、25%、50%、75%、100%、125%、150%、200%、250%，捏合或加减后显示实际比例。触控板捏合以光标位置为中心缩放；“缩放设置”悬浮显示文字提示，可调灵敏度 0.5×～6×，步长 0.1×，默认 3.5×，记住本机选择，点击画布或面板外部自动收起设置，面板内调整滑杆时保持展开，普通双指滚动仍用于平移。流程说明页按实际内容高度展示，默认缩放到完整可见；可放大阅读，点击「适应画布」恢复完整显示。

分享版保留搜索、定位页面和查看标记说明，修改能力关闭；接收者可通过顶栏「导出」导出离线工作台 HTML 或需求文档 `.md`，无需连接原工作台，导出内容以收到的分享文件为准。通用 HTML 在隔离的页面中运行自己的脚本，通过已声明的控件绑定与截图热点连续跳转。项目也可通过显式扩展提供声明式播放器：页面脚本会被移除，交互由扩展处理；相同扩展随项目的离线 HTML 内嵌。

## 整理与查找

- 选中节点后，右侧移除常用操作区的打开、聚焦、编组入口；多选时提供六种对齐及横向、纵向等间距，不提供复制或创建副本按钮。对齐以第一个选中节点为基准，等间距保留首尾位置。方向键移动 1 px，Shift＋方向键移动 10 px。F 聚焦所选，无选择时适应整张画布。
- ⌘C / Ctrl+C 复制、⌘X / Ctrl+X 剪切、⌘V / Ctrl+V 粘贴所选页面或流程；剪切仅在成功写入剪贴板后移走原节点及关联关系，支持撤销；跨模块引用只移除当前画布的引用，不删除来源页面。⌘D / Ctrl+D 创建副本。复制仅携带所选内容及其依赖组件、说明图片；剪切、粘贴后仅增删或更新受影响卡片，保留其他缩略图，后台过期响应不覆盖刚完成的编辑。副本保留相对位置、组内真实操作链、批注与独立的交互说明，关联的隐藏状态一起复制并继续隐藏，布局避让已有节点。HTML 状态使用独立路径，普通 HTML 在首次保存时复制源文件；截图沿用图片资源，替换副本截图不影响原节点。
- 跨项目粘贴会将截图、说明图片和普通 HTML 及其组件复制到目标项目；来源或目标项目使用专用扩展时，包含 HTML 的粘贴会提示交给 Agent 迁移，避免缺失交互。若此前已剪切且粘贴被拦截，可回来源项目粘贴找回所选内容，并核对它与未选节点的连线。
- 不提供编组、编组名称或编组快捷键；页面独立选择，可通过框选或 Shift 临时多选后一起移动。复制粘贴不携带编组，新增或复制不会重排已有内容。
- 左侧只保留一个“搜索页面”入口，按名称部分匹配所有模块的画布页面。结果只显示页面名称和所属模块，单击整行切换到所属模块画布、居中缩放并选中目标，不直接打开详情；目录中的页面也只用于定位，双击画布节点才打开页面。搜索词和结果在定位后保留，清空后恢复模块列表；无结果显示“未找到相关页面”。隐藏的重复状态按 `overviewAlias` 命中保留节点并合并结果，没有可见对应节点的独立隐藏页面不列入搜索，页面内交互仍保留。不提供“全部页面”弹窗、显示状态筛选及显示／隐藏操作。⌘K / Ctrl+K 展开目录并聚焦搜索框。
- 鼠标悬浮或键盘聚焦模块行时显示排序把手和删除图标；所有模块使用同一删除操作。把手可拖动排序，也可用上下方向键调整顺序。
- 选中连线后，可用线段中点始终显示的细长绿色手柄横向或纵向调整折线，拖动时可对齐同线其他拐点或端点（按 Alt 取消对齐），松手自动合并微小弯折，双击手柄恢复自动路径；拖动说明文字沿当前连线轨迹滑动调整 `labelT`，四边端点与边框锚点继续随页面移动。手动调整与撤销、保存及分享导出一致。
- 左侧“回收站”直接打开画布，从左侧模块目录切换回对应模块；画布顶部不另设标题、操作提示或返回栏。隐藏的原型页面、图片和说明按四列网格排列，卡片标注所属模块，使用完整等比缩略图。支持缩放、平移、框选、Shift 多选、拖动及双击预览；回收站位置独立保存，预览返回保留画布位置。选中内容直接复制或剪切，到模块画布粘贴为正常可见节点；复制保留回收站原件，剪切移走所选原件，均保留说明和标记。也可向回收站粘贴，内容继续隐藏。没有“放回画布”按钮、列表视图或第二个搜索入口；现有节点删除行为保持不变。
- 图片上传支持多选，粘贴或拖入多张图片按行排列，避让已有节点；本次导入按一次撤销处理，不移动原来的画布。
- 打点后在标记旁直接输入，浮层提供文本框、删除、取消和保存，不提供语音，保存后右侧按编号显示内容；不提供独立评论列表、处理状态或关联说明区域。页面说明与交互规则正文合并为一个编辑区，保留已有文字。

节点和模块删除后立即生效，不弹出浏览器确认框；误删可使用顶部撤销或 ⌘Z / Ctrl+Z 恢复。

所有按钮和图标按钮统一使用悬浮文字提示，说明对应功能；提示在点击或滚动时收起。标记说明点击保存提交，其他编辑自动保存到当前项目，打开时读取最新内容，不提供版本列表或恢复操作。

## 连线

每条连线独立避开节点，不以其他线为障碍，不交换端口或整理其他路径；新建时只生成新线，改接时仅重新生成被改接的线，移动节点时仅处理端点改变或受影响的线。有效的手动折线允许自由穿过卡片，保留用户调节结果；单侧节点移动时尽量保留中间折点形态，只衔接贴近端点的首尾邻段。

连线默认使用飞书式圆角折线，也支持从 JSON 数据渲染直线（`straight`）、三次贝塞尔曲线（`curve`）、虚线（`dashed`）及单向／双向／无箭头，越过其他连线时在交叉点自动绘制 r=6 半圆跳弧（邻近交叉合并为胶囊桥）。鼠标悬浮或选中页面即在卡片外侧 14px 处显示四向带箭头圆点；拖线时目标卡片连接点贴回边框，并依次按四向连接点磁吸、边框轮廓任意点连续吸附（实时显示吸附圆点）与卡片内部自动择侧响应，按住 Shift 可吸附 45°/90° 方向；拖到空白处的预览带滞回。拖到空白处松手或按 Esc 取消，不新增节点。双击线条或文字、或选中连线后直接键入 / 按 Enter / F2 即可原地编辑名称，输入框按当前画布缩放同步匹配标签字号与高度，Enter 保存、Esc 取消；拖动文字沿路径调节 `labelT`（近中点时自动居中吸附），旧编排 `labelPosition` 自动投影吸回连线上。

箭头位于节点上层，尖端贴合节点边缘，缩放时保持大小。选中连线后，两端改接把手始终可见，贴合卡片边缘与箭头对齐，不被卡片裁切。

分叉点靠近目标页面时，引线长度随可用间距缩短，避免固定引线把支线挤到页面另一侧再折返；实际手动折点仍按已有规则保留。

历史编排中的分叉点（`presentation: "branch"`）仍显示为小圆点，拖动时对齐其他端点，从已有分叉的连接点继续拖线可扩展分支；多条实际按钮共用一条可见连线时，右栏会自动解析跨越分叉点的真实起终点页面并保持各按钮跳转、条件与说明独立。工作台不在画布连线上悬浮「＋」按钮或连线悬浮工具栏；连接点、改接把手和分叉点保持小而稳定的屏幕尺寸，放大时不变大，缩小时最多收到 60%，可抓取范围由不可见的扩大热区保证。

不提供「重排所选流程」。页面位置由用户拖动整理，也可使用对齐和等间距；新增、改接、删除连线与从线上新增分支均保留已有页面位置。

图算法与离线解压依赖、固定版本和许可证见[内嵌依赖](../runtime/THIRD-PARTY-README.md)。离线分享沿用相同的布线行为。

## 本地接口

`GET /api/project/status` 只返回编排与资源版本，未变化时不下载页面和图片，后台标签页暂停轮询；`GET /api/project` 读取项目和页面资源；`PUT /api/project` 以文件版本核对保存；`POST /api/image` 保存图片；`POST /api/clipboard/import` 复制跨项目所需的资源；`POST /api/export` 内嵌当前范围生成 HTML。写入请求需要本地会话令牌。仅监听本机，文件访问限定在选中项目内。

日常修改项目内容只检查受影响文件的语法、引用和业务一致性。`npm test` 是维护元形源码的回归入口（仅源码仓库提供，安装包不含），范围见[按影响验证](agent-adaptation.md#按影响验证)，不作为每次设计的必经步骤。
## 项目与完整原型

顶栏左侧切换已登记项目，中间切换「流程画布／需求文档／完整原型」，右侧保留当前视图所需操作。新增项目、模块归属、产品入口和交互串联可直接通过对话交给 Agent；工作台不增加项目管理表单。

同一产品的模块共享一份完整原型，沿页面自身的导航连续操作。确属独立产品或平台时才显示产品／平台选择，不按模块列体验入口。画布节点记录页面的初始状态，打开后可继续操作并改变状态；连线表达重点流程，不限定页面中其他已有操作。有设计的交互应可操作，没有设计的功能不补造。

画布和回收站仅在页面进入视野附近时分批创建静态缩略预览，离屏后释放 iframe；缩略图不承载交互。双击节点打开完整页面，复制、剪切、粘贴和位置保留不受预览加载影响。

普通 HTML 和支持原生交互的声明式项目可由页面内实际控件接收鼠标和键盘事件，保留原生悬浮、焦点、滚动和表单；声明式项目需由其扩展挂载页面交互，并显式启用节点原生交互，否则打开节点沿用原代理机制。截图继续使用热点，批注与绑定区域使用工作台编辑层。浮动菜单相对当前触发元素定位。

完整原型中，按钮关联的图片在预览层打开，点击「返回」或按 Esc 回到来源页，保留来源页的输入和滚动位置。图片之间可沿已有热点继续跳转并逐层返回；热点指向页面时继续原流程。


## 局部 UI 开发交付

右上角「⋯ → 开发交付模式」切换，默认关闭。开启时顶栏显示「开发交付中 · 退出」、蓝色状态点和底边提示，更多入口也显示选中状态；点击状态提示即可退出。普通画布、原型体验不显示拾取工具。开启后打开 HTML 页面，点击需要交付的区域，通过上方的层级按钮选择更大的父级区域；可复制交付内容、复制 HTML 或下载片段 HTML。退出按钮或 Esc 关闭此模式。

模式使用只读预览，保留原页面 iframe，退出后恢复原来的页面与输入。普通脚本页面通过受会话令牌约束的页面桥传回当前 DOM 快照；不会为提取而放开原页面的脚本权限。截图与说明节点不提供 DOM 提取。

交付内容包含页面和模块背景、预览路径、项目扩展提供的编辑源文件、选区 DOM、页面样式、组件标记、SVG 符号依赖、页面与关联标记说明。下载片段保留祖先容器及 body 属性作为布局上下文，兄弟区域不一起导出；脚本、事件处理和拾取高亮不进入片段。片段用于局部 UI 对照，原页面交互与真实业务实现仍应沿用项目源。

## 修改说明与跨页面同步

页面和连线的画布说明只保留核心事项，直接编辑更新当前对象的摘要，完整规则继续在需求文档或源说明中维护；离线分享保持说明只读。

需要跨页面调整时，在使用元形的当前对话中提出范围与规则，例如“所有涉及安装技能的地方，都改成安装后默认对全部专家启用”。Agent 根据业务含义查找相关页面、说明和交互，核对并同步本轮范围内的内容，再说明受影响的位置与差异；不只匹配相同逻辑标识或字面文本。工作台不增加共用逻辑管理入口或独立 AI 输入框，当前页编辑也不自动触发跨页修改。
