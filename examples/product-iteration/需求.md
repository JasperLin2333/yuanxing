# 客户分配需求

## 1 需求目标

### 1.1 背景

客户列表已有客户信息，需要让管理员从列表为待分配客户指定负责成员。

### 1.2 目标

管理员能完成选择、确认和结果查看；普通成员从同一入口看到权限提示。

## 2 功能清单

| 功能 | 本次变化 |
| --- | --- |
| 客户列表 | 增加分配入口，保留原有客户信息 |
| 分配表单 | 选择一位负责成员，支持确认与取消 |
| 分配结果 | 展示所选成员，支持返回客户列表 |
| 权限提示 | 普通成员进入同一入口时提示权限边界 |

## 3 需求详情

### 3.1 从客户列表发起分配

- 管理员点击【分配客户】进入表单，显示本次需要分配的客户。
- 普通成员点击同一入口进入权限提示，点击【返回列表】回到客户列表。

### 3.2 选择负责成员

- 【分配给】默认未选择，只能选择一位成员。
- 未选成员时，确认操作由表单必填校验拦截，停留当前表单。
- 选择成员后点击【确认分配】，进入完成页并展示本次所选成员。
- 点击【取消】返回客户列表。

### 3.3 查看分配结果

- 完成页显示所选成员。
- 点击【返回客户列表】返回原列表。
